Amazon Q in QuickSight allows business executives and engineers to ask natural language questions about AWS spending.

## Example Questions to Ask Amazon Q

- *"What were my top 3 most expensive AWS services last month?"*
- *"Show me EC2 spend breakdown by instance type for August 2026."*
- *"Why did S3 cost increase last week?"*

{{< note >}}
Amazon Q uses the underlying QuickSight data models and Athena datasets to generate real-time visual answers.
{{< /note >}}
