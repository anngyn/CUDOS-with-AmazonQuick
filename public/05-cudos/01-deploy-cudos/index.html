Deploy CUDOS v5 Dashboards

Overview

CUDOS v5 consumes the CUR/Athena layer and publishes interactive cost intelligence through Quick Sight. AWS documents a v5 design using SPICE-backed summary, resource, and hourly datasets.

Learning Objectives

  • Understand the deployment prerequisites.
  • Deploy the current CUDOS v5 release.
  • Inspect Quick Sight datasets.
  • Verify SPICE ingestion.

Why This Matters for FinOps

CUDOS reduces the engineering required to create broad cost visibility, but it still depends on correct cost semantics and fresh upstream data.

Architecture Context
